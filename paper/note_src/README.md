## Rebuild

```
cp ../staleline/paper/numbers.tex numbers.tex     # after pulling main, if numbers changed
python3 check_note.py                             # runs make_tables.py, then make_fmt.py, compiles, runs all checks, writes numbers_sheet.md
```

check_note.py fails on: missing keys, em/en dashes or "--" in main.tex, bare "Polymarket", body longer than
5 pages (page of \label{endofbody} in main.aux). It warns on SURNAME / CHECK TITLE placeholders and lists
typed digits and overfull boxes.
